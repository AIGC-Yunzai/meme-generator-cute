# 字幕表情的字幕位置按参考截图反推，不居中、不贴底

`memes/honestMoney/` 的三张素材是同一批 16:9 截图（1672×941）去掉字幕后的版本，构图一致
（脸部特写、下巴落在底部中央），因此共用一组字幕区。参考帧是同一画面的原带字幕截图
（1920×1080）：中文那行墨迹落在 y 922..964、x 743..1176，水平中心 959.5 与图宽中心 960 重合，
日本语那行在 y 978..1022。按 0.871 的比例折算到素材上，单行中文的墨迹应落在 y 803..840、中心 821。

我们把这个位置当作字幕区的**垂直中心**，而不是把单行字幕居中到原双语块的中心（那会下移约 25px），
也不贴底。理由是：这个表情的观感价值就是「看起来像原片自带的一行字幕」，
和原片字幕行错开 25px 会被看出来，贴底则一眼不像正片字幕。
代价是单行时底部留白偏多（约 100px），这是刻意的。

字幕区实际取值 `(251, 748, 1421, 896)`：中心 y=822，宽 70% 画面，高按 54px 字号两行（142）留 6px 余量。
宽度不是「左右各留 8%」（原始需求里写的是 8%），实施时改成了 70%——按 84% 试渲染时，
三十来字的句子会摊成一条 1300px 宽、几乎顶到画面两侧的行，完全不像字幕；
收到 70% 后同一句话会先折成两行。这是**有意偏离**，不是没对齐。

实测（字号 54、描边 0.07）：单行绘制范围 y 794..855（含描边），水平中心 835.5，
与目标中心 821 差约 3px——字形上下不对称导致，肉眼无差，不再微调。

## 后果

- 长句折行时以原字幕行为块中心上下扩展，而不是一路往下长到画面边缘；40 字的两行成品
  绘制范围是 y 758..890。
- 本类表情**不走** `measure_bubble.py`：它用洪水填充找气泡内部，字幕表情没有气泡可量。
- 文字颜色也不按 `AGENTS.md` 里「取气泡描边同色系」那条约定，固定为纯白字 + 纯黑描边
  ——这是在模仿原片字幕，不是在模仿气泡自带的字。描边的**实现方式**（alpha 膨胀，
  因为 emoji 不认 `stroke_fill`）见 ADR-0004。
- 换一批素材必须重新量，这组数字来自这一帧的具体构图，不能沿用。
