# 多图表情用 `-n/--number` 选图，`0` 表示随机

凡是「一套素材、用户挑一张」的表情，都走同一条路：`args_model` 里一个 `number: int = Field(0)`，
配 `ParserOption(names=["-n", "--number"])`；`0`（默认）表示随机，`1..N` 表示指定，
越界抛 `MemeFeedback`。`elysia_holdsign` 已经这么写了，`honestMoney` 沿用。

考虑过的替代：从 `0` 开始编号（`0..2`）—— 与「`0` 表示随机」这个哨兵值直接冲突，
而且素材按 `01.png` 起名会让索引和文件名整体差一；改用 `--image` 之类的名字 ——
下游适配器对 `-n` 已经形成肌肉记忆，换名字只增加迁移成本。

## 后果

- 参数是 1 基的，`0` 永远不是「第一张」。
- 素材文件按 `01.png`、`02.png` … 编号，编号与文件名对齐，不需要额外的映射表。
