# 字幕描边用 alpha 膨胀，不用 `draw_text` 的 `stroke_fill`

`draw_text(stroke_fill="black", stroke_ratio=0.07)` 只对**矢量字形**生效。彩色 emoji 是位图字形，
skia 不认描边 paint——`🐷🐷侠` 里两个猪没有任何轮廓，压在浅色皮肤和白卫衣上直接糊成一团，
只有右边那个汉字有黑边，一行字看起来像坏了一半。用户报的就是这个。

所以改成两步：先把文字画到一张全尺寸透明层（不描边），再取这层的 **alpha 通道做膨胀**
（`ImageFilter.MaxFilter(2r+1)`），用膨胀结果当蒙版涂黑，最后把「黑边层」压在「文字层」下面。
膨胀只看透明度、不看颜色，所以彩色 emoji 和汉字会得到同一套轮廓——这正是 `stroke_fill`
做不到的地方。

考虑的替代：给 emoji 单独画一遍黑色再偏移 8 个方向（常见的假描边）。不行——那一遍画出来的
emoji 仍是彩色的（位图字形不认 `fill`），假描边对 emoji 完全无效。

## 后果

- 描边宽度变成**像素半径**（`SUBTITLE_OUTLINE = 3`），不是原来按字号算的比例。
  skia 的 `stroke_width=4` 是「总宽」、外侧只有 2px；膨胀 3 是一边就长 3px，所以汉字会比
  原来略粗一点。这是为 emoji 可读性付的代价，要完全还原旧观感就把半径降到 2。
- 每次渲染多一张全尺寸透明层和一次 MaxFilter（1672×941 上毫秒级），可忽略。
- 膨胀的边角是方形而非 skia 的圆角，3px 尺度上看不出来。
- emoji 本身的字形比汉字小一圈（Segoe UI Emoji 的位图尺寸与 CJK 字体 em 不一致），
  加了描边只是让它「看得见」，不会让它「和汉字一样大」。要等大得单独按字宽排版，暂不做。
