# 字幕字号固定 54px，不做「放不下就自动缩字」

`honest_money` 的字幕字号写死 54（`max_fontsize == min_fontsize`）。`pil_utils.draw_text`
的行为是：从 `max_fontsize` 每次减 1 试到 `min_fontsize`，仍放不下才抛 `ValueError`。
两个值设成同一个数，就等于「固定字号，画不下直接报错」，再由表情转换成 `TextOverLength`。

考虑过的替代是原先的 44→26 自适应。放弃它的原因：**自适应会让同一个表情在不同句子上
出现不同字号**——短句 44、长句 38，同一张脸的字一会大一会小，发到群里像换了个人。
放大字号时这个问题更明显：想让它「大一点」，写 44→26 不管用，长句照样缩回去。
现在 54 是下限也是上限，任何长度的文字都同号，最多折两行。

## 后果

- 可接受的文字长度有了硬上限：约 42 个汉字（两行 × 每行约 21 字）。超过直接抛 `TextOverLength`，
  不会再悄悄把字缩小到「勉强能看」。
- 调字号要同时改 `SUBTITLE_FONT_SIZE` 与 `SUBTITLE_AREA` 的高度（54px 两行是 142px），
  只改字号会让两行放不下、全部退化成 `TextOverLength`。
- **字号按画面高度定，不按像素拍脑袋**：1672×941 的素材上 54px ≈ 画面高度的 5.7%
  （参考帧 1080p 加字幕是 50px ≈ 4.6%，这里刻意比原片大一档，小屏上更清楚）。
  换尺寸不同的素材按同一比例换算：1080p → 62，720p → 41，再回来改区域高度。
